
# [Surge] GL Historic Transaction Loading

## Descrição

### Summary

SAP-approved approach for loading historic General Ledger transactions into S/4HANA via Migration Cockpit. Includes validated posting logic, documented constraints, and Clean Core / SAP PQ-compliant code.

**Target Table: ACDOCT** (Universal Journal Entry Totals) — NÃO ACDOCA (line items).

### Business Value

GL history is the foundation for financial reporting, trend analysis, and planning in S/4HANA. Without loaded GL history, customers cannot produce comparative financial statements, run year-over-year analyses, or perform planning against historical actuals in the target system. This epic delivers a repeatable approach for the most foundational transaction type.
